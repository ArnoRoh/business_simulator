# CLAUDE.md

**Read [`AGENTS.md`](./AGENTS.md) first.** It is the single canonical operating guide
for this repository and applies in full to Claude.

This file exists only so that Claude Code discovers the guide automatically. Do not
duplicate guidance here — if something needs saying, it belongs in `AGENTS.md`.

## Before you do anything

1. Read [`AGENTS.md`](./AGENTS.md) — especially §2 (the thesis) and §5 (the memory
   protocol).
2. Read [`memory/PROJECT_STATE.md`](./memory/PROJECT_STATE.md) — where the project
   stands right now.
3. Read [`memory/OPEN_QUESTIONS.md`](./memory/OPEN_QUESTIONS.md) — what is unresolved.
4. Skim the most recent entries in [`memory/sessions/`](./memory/sessions/).

## Before you finish

Update memory as described in `AGENTS.md` §5: write a session entry, refresh
`PROJECT_STATE.md`, log any decisions in `DECISIONS.md`, and commit those updates
alongside the work they describe.

Skipping this is the single most damaging thing you can do in this repository. Context
that is not written down is lost the moment the session ends.
